# FPGA UART 센서 통합 시스템 (미니 프로젝트)

Basys-3 FPGA에 스톱워치, 시계, 초음파 거리 센서(HC-SR04), 온습도 센서(DHT11)를 하나로 합친 Verilog 미니 프로젝트입니다.
보드의 버튼과 스위치로도 조작할 수 있고, PC 터미널에서 ASCII 문자 한 글자로 명령을 보내면 해당 기능이 동작하고 결과값이 다시 PC로 전송됩니다.

- 기간: 2026.08.17
- 보드: Basys-3 (Artix-7, 100MHz)
- 도구: Vivado, Verilog

## 구성

```
PC 터미널 ──RX──> UART RX ──> RX FIFO ──> ASCII Decoder ──┐
                                                          ├──> Control Unit ──> Stopwatch / Watch Datapath
버튼 4개 (디바운스) / 스위치 4개 ─────────────────────────┘                   ├──> SR04 Controller
                                                                              └──> DHT11 Controller
FND 4자리 <── FND Controller <── 모드별 표시값 MUX
PC 터미널 <──TX── UART TX <── ASCII Sender (숫자 4자리 + CR LF)
```

| 모듈 | 하는 일 |
|---|---|
| `uart_controller` | 9600bps UART 송수신, 16배 오버샘플링 baud tick |
| `uart_rx_fifo` | 받은 문자를 잠깐 저장했다가 디코더로 한 글자씩 넘김 |
| `ascii_decoder` | 받은 문자를 기능별 1클럭 펄스와 모드 선택 신호로 변환 |
| `control_unit` | 버튼, 스위치, UART 명령을 받아 스톱워치 / 시계 / 센서 동작 결정 (FSM) |
| `stopwatch_datapath`, `watch_datapath` | 1/100초, 초, 분, 시 카운트. 스톱워치는 기록 저장, 시계는 시간 설정 |
| `sr04_controller` | Trig를 약 11µs 내보낸 뒤 Echo가 High인 시간을 µs 단위로 세서 거리(cm) 계산 |
| `dht11_controller` | START, WAIT, SYNC, DATA 순서로 40비트를 읽고 체크섬 확인 |
| `ascii_sender` | 표시값을 숫자 4자리 ASCII와 CR LF로 바꿔 PC로 전송 |
| `fnd_controller` | 4자리 FND 다이나믹 구동 |

## 모드 선택

| 스위치 | 모드 |
|---|---|
| 모두 OFF | 스톱워치 |
| SW1 | 시계 |
| SW2 | 초음파 거리 |
| SW3 | 온습도 |
| SW0 | 표시 전환 (초.1/100초 / 시.분) |

스위치를 바꾸면 스위치가 우선이고, 그 외에는 마지막으로 받은 UART 명령의 모드를 따릅니다.

## UART 명령 (9600bps, 1글자)

| 문자 | 동작 |
|---|---|
| `r` / `s` / `c` / `m` | 스톱워치 시작 / 정지 / 초기화 / 표시 전환 |
| `H` / `M` / `S` | 시계의 시 / 분 / 초 조정 |
| `U` / `D` | 시계 조정 방향 (증가 / 감소) |
| `h` / `t` | 습도 / 온도 측정 |
| `d` | 거리 측정 |

- 스톱워치와 시계는 버튼이나 명령이 들어올 때마다, 센서는 측정이 끝날 때마다 현재 값을 숫자 4자리 + CR LF로 PC에 보냅니다.
- DHT11은 체크섬이 맞을 때만 값을 보내고, 정의되지 않은 문자는 무시합니다.

## 버튼

| 모드 | 왼쪽 | 오른쪽 | 위 | 아래 |
|---|---|---|---|---|
| 스톱워치 | 시작 / 정지 | 초기화 | 표시 전환 | 동작 중이면 기록 저장, 정지 중이면 저장한 기록 보기 |
| 시계 | 시 조정 | 초 조정 | 분 조정 | 조정 방향 감소로 |
| 초음파 | 측정 | | | |
| 온습도 | 습도 | 온도 | | |

## 구현하면서 신경 쓴 부분

- UART 명령과 버튼이 같은 기능을 쓰도록 디코더 출력을 1클럭 펄스로 맞춰서 Control Unit 하나로 처리했습니다.
- 받은 문자를 FIFO에 넣어서, 디코더가 처리하는 동안 다음 문자가 들어와도 놓치지 않게 했습니다.
- 센서 측정 요청은 측정이 끝날 때까지 busy로 막아서, 버튼을 여러 번 눌러도 측정이 겹치지 않게 했습니다.

## 실행

Vivado에서 새 프로젝트를 만들고 `rtl/` 파일을 모두 추가한 뒤 `top_uart_sensor`를 Top으로 지정합니다.
Basys-3 핀 설정(xdc)을 포트에 맞게 추가하고 비트스트림을 만들어 보드에 올립니다.
